# TaskFlow Web

Frontend for TaskFlow — React + Vite + Tailwind.

## Quick Start

```bash
cp .env.example .env
npm install
npm run dev   # runs on :3001
```

## Pages

- **Dashboard** — task stats overview
- **Tasks** — full task table with priority/status
- **Analytics** — sprint velocity, burndown chart
- **Team** — workload distribution per team member
